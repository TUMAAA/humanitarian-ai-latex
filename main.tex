% Note on per-subproject templates: \documentclass above is fixed at
% compile time, so every subproject built through this root file shares
% it, and subfiles requires each subproject's own main.tex to declare
% this same root. If a specific subproject ever needs a genuinely
% different template (different class, different conference style), the
% clean way to do that is to NOT use \documentclass[../main.tex]{subfiles}
% in that subproject's main.tex -- give it its own full \documentclass
% and preamble instead, and compile it directly (e.g.
% pdflatex research_proposal/main.tex) rather than through this root
% file. That subproject then simply won't be reachable via the
% \subproject switch above, which is a reasonable tradeoff for a one-off,
% differently templated document.
